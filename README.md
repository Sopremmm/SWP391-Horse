# SWP391 Horse Racing Tournament Management System

Full-stack system for managing horse-racing tournaments, participants, races,
results, and role-based operational workflows.

## Repository structure

```text
backend/          Spring Boot API (Java 17)
frontend/         React client (TypeScript)
database/         Database schema and setup notes
docs/             Architecture, UML, reports, mockups, and debugging notes
postman/          Postman collection and environment
tests/e2e/        End-to-end QA utilities
```

Each application contains its own setup notes and dependency manifest. Generated
outputs, local IDE settings, secrets, and machine-specific debug files are
excluded from version control through `.gitignore`.
